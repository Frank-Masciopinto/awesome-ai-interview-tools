# Contribution Guidelines

Thank you for your interest in contributing to Awesome AI Interview Tools! 🎉

## Adding a new tool

Please ensure your pull request adheres to the following guidelines:

- **The tool must be real and actively maintained.** Please include only tools that actually exist and are functional.
- **Use the following format:** `[Tool Name](https://link.com) - A short, clear description of the tool.`
- **Add the tool in the appropriate category.** If no suitable category exists, create one.
- **Keep descriptions concise.** One or two sentences max.
- **Check your spelling and grammar.**
- **Remove any trailing whitespace.**
- **New categories or improvements to the existing categorization are welcome.**

## Pull Request Process

1. Fork the repository
2. Create a new branch (`git checkout -b add-tool-name`)
3. Make your changes
4. Commit with a clear message (e.g., `Add ToolName to real-time assistants`)
5. Push and open a PR

## Quality Standards

- The tool must be relevant to interview preparation, practice, or assistance
- No duplicate entries
- The link must be working and point to the official website
- Both English and Chinese versions of the README should be updated if applicable

Thank you for helping make this list better! 🚀
